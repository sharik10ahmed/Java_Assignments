## 📖 About The Repository

Welcome to the **Java Assignments** repository! This project serves as a structured log of daily programming exercises, designed to build a strong foundation in Java programming. From basic syntax and operations to working with arrays and advanced logic, each "Day" folder encapsulates specific concepts and logical problems to master Java step-by-step.

Whether you are a beginner looking for practice problems or an experienced developer brushing up on core concepts, you'll find a variety of well-organized, clean, and tested Java solutions here.

## 🗂️ Repository Structure

The coursework is divided into a daily structure, progressively increasing in complexity. Here is a general overview of the progression:

| Day | Topics Covered | Highlighted Concepts & Exercises |
| :---: | :--- | :--- |
| **Day 1** | Introduction to Java | `FirstClass.java` - Basics, main method, output formatting |
| **Day 2 - 7** | Core Fundamentals | Variables, Data Types, Control Flow, Loops, Operators |
| **Day 9** | Logic Building | Pattern printing, number manipulation, conditional logic |
| **Day 10** | Arrays & Sorting | Array syntax, min/max algorithms, custom sorting algorithms |
| **Day 11 - 13** | Advanced Concepts | Object-Oriented Programming (OOP), String manipulations |

*(Note: The repository is continuously updated with new assignments and exercises.)*

## 🚀 Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

- **Java Development Kit (JDK):** Ensure you have JDK 8 or higher installed on your system.
  ```bash
  java -version
  ```

### Installation & Execution

1. **Clone the repository:**
   ```bash
   git clone https://github.com/sharik10ahmed/Java_Assignments.git
   ```
2. **Navigate into the project directory:**
   ```bash
   cd Java_Assignments
   ```
3. **Compile a Java file** (Example for Day 10 - Array Sorting):
   ```bash
   cd Day_10
   javac sort_arr.java
   ```
4. **Run the compiled Java class:**
   ```bash
   java sort_arr
   ```
